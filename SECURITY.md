# Security

Please don't report security problems in public issues or pull requests.

Report them privately instead, by either:

- the **Report a vulnerability** button on this repository's **Security** tab
  (GitHub private vulnerability reporting), or
- email to security@invideo.io.

Include what you found, how to reproduce it, and which version of the CLI or
install script it affects. We'll acknowledge your report and keep you updated
while we fix it.
