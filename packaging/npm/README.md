# invideo CLI

invideo is a professional video editor you can drive from the terminal or your
agent, with 250+ AI models for images, video, voice and music.

```sh
npm install -g @invideo-ai/cli     # or: npx @invideo-ai/cli
invideo auth login
invideo project list
```

`invideo help` lists everything. Docs, other installers and releases:
[github.com/invideoio/cli](https://github.com/invideoio/cli).
